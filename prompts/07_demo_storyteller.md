# Prompt — Demo Storyteller

You own the ShelterWise pitch and demo. Read `docs/PRODUCT_BRIEF.md`, `docs/DEMO_SCRIPT.md`, `docs/ARCHITECTURE.md`, and `docs/LEGAL_AND_SAFETY_GUARDRAILS.md`.

Create a compelling, honest 3–4 minute demonstration:
- Start with a clear tenant problem, not architecture.
- Use one realistic, clearly labeled sample scenario.
- Show intake → fact review → evidence → legal/resources → evidence gaps → generated brief.
- Include one example of a legitimate decoy exclusion and explain the reason.
- State the key evidence limitation: public records provide context and do not prove conditions inside a tenant's unit.
- Show citations and human review.
- Explain what is novel technically without overclaiming.
- Close with the practical value for tenants and housing advocates.

Avoid marketing language, unsupported impact statistics, claims that ShelterWise prevents eviction, and claims of legal eligibility determination. Prepare:
1. a spoken script with timestamps;
2. a fallback script if live retrieval fails;
3. three likely judge questions with concise answers;
4. a one-slide architecture explanation;
5. a final checklist for demo readiness.
